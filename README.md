# 내집어디 — 서울 아파트 대시보드

서울 아파트 단지 마스터와 수집된 실거래 신고 자료를 비교하는 대시보드입니다.

## 주요 기능

- 자치구·전용면적·가격·준공연도·지하철·직장 접근 조건 검색
- 최근 거래가 없는 단지도 포함한 단지 목록 (마스터 범위와 거래 수집 범위는 다릅니다)
- 면적별 매매·전세 차트, 전세가율, 매매·전월세 거래 목록
- 위치 지도·교통·학교 정보, 결과 Excel 다운로드, 모바일 상세 패널

## 데이터 운영

공개 GET 요청은 **저장된 D1 자료만 조회**합니다. 새로고침이나 팝업 열기로 MOLIT 수집·DB 쓰기가 발생하지 않습니다.

GitHub Actions의 별도 수집 작업에서 구·월·매매/전월세별 모든 페이지를 확인한 뒤 인증된 관리자 엔드포인트로 적재합니다. 완전한 자료만 공개 버전으로 교체하고, 실패하면 마지막 정상 자료를 유지합니다.

- 미수집/조회 실패와 수집 완료 후 거래 0건을 구분합니다.
- 실시간 시세나 매물 호가가 아닙니다. 계약일과 수집 시각을 따로 표시합니다.
- 인증키나 자료가 없을 때 예시 가격·가상 차트를 만들지 않습니다.
- 신규 수집 가격은 정수 만원으로 저장하고 화면에서 억원으로 변환합니다.
- 매매는 2006-01, 전월세는 2011-01 이후 중 실제 수집된 범위만 제공됩니다.
- 단지 매칭 실패 관측도 보관합니다. 전체 단지 확보·매칭 품질은 별도 점검 대상입니다.

**[실거래 수집 운영 안내](docs/trade-ingestion.md)를 먼저 확인하세요.** 코드 병합만으로 과거 거래 데이터가 자동 확보되지는 않습니다.

## 개발 및 검증

Node.js 22.13.0 이상을 사용합니다.

```bash
npm ci
npm run dev
npm test
```

로컬 D1/외부 서비스가 연결되지 않아도 내장 단지 목록을 확인할 수 있지만, 미확인 가격은 표시하지 않습니다. 변수 이름은 [.env.example](.env.example)을 참고하세요. 비밀키를 소스·URL·공개 변수에 넣지 마세요.

DB 스키마 변경 시 `npm run db:generate`로 생성한 SQL·메타데이터를 함께 커밋합니다. 이미 적용한 마이그레이션을 수정하지 않습니다. 배포 시 마이그레이션 적용 후 새 Worker를 배포해야 합니다.

## 출처와 주의

국토교통부 실거래 신고 자료는 취소·정정될 수 있습니다. 화면 가격은 억원, 전용면적은 ㎡ 기준입니다. 수집 범위·시각을 확인하고 원문 및 현장 정보를 함께 확인하세요.
