# 내집어디 — 서울 아파트 대시보드

서울 아파트 단지 마스터와 수집된 실거래 신고 자료를 비교하는 대시보드입니다.

**공개 사이트: https://yuhyukkim.github.io/realestatedash/**

## GitHub-only 운영

- 소스·공개 데이터는 `main`에서 관리합니다.
- main 푸시 → GitHub Actions 검사·정적 빌드 → GitHub Pages 배포
- `Collect MOLIT snapshots`를 main에서 실행하면, 수집·검증된 자료만 커밋하고 사이트를 다시 배포합니다.
- 인증키는 GitHub Actions Secret `MOLIT_API_KEY` 하나에 보관합니다. 매매·전월세 서비스 각각의 활용 승인은 필요합니다.
- Cloudflare 자동 빌드 연결과 GitHub 내 Cloudflare 배포 작업은 해제했습니다. 기존 Worker·DB는 별도로 보존합니다.
- **[설정·수집·장애 대응 안내](docs/GITHUB-PAGES.md)**

## 주요 기능

- 자치구·전용면적·가격·준공연도·지하철·직장 접근 조건 검색
- 최근 거래가 없는 단지도 포함한 단지 목록 (마스터 범위와 거래 수집 범위는 다릅니다)
- 면적별 매매·전세 차트, 전세가율, 매매·전월세 거래 목록
- 위치 지도·교통·학교 정보, 결과 Excel 다운로드, 모바일 상세 패널

## 데이터 운영

방문자는 GitHub Pages에 게시된 JSON만 조회합니다. 새로고침이나 팝업 열기로 공공 API 수집·DB 쓰기가 발생하지 않습니다.
Actions가 구·월·유형별 모든 페이지를 확인한 뒤 정제한 공개 관측값을 `data/scopes/`에 저장합니다.
수집에 실패하거나 검증·빌드가 실패하면 이전 공개 데이터를 유지합니다.

- 미수집/조회 실패와 수집 완료 후 거래 0건을 구분합니다.
- 실시간 시세나 매물 호가가 아닙니다. 계약일과 수집 시각을 따로 표시합니다.
- 인증키나 자료가 없을 때 예시 가격·가상 차트를 만들지 않습니다.
- 가격은 정수 만원으로 저장하고 화면에서 억원으로 변환합니다.
- 매매 2006-01, 전월세 2011-01 이후 중 실제 수집된 범위만 제공합니다.
- 미매칭 거래도 정제 관측값으로 보관하고 집계합니다. 단지 팝업에 임의로 연결하지 않습니다.
- 코드 병합만으로 서울 전체·장기 거래 이력이 자동 확보되지는 않습니다. 최초 검증 이후 구·기간을 나누어 수집하세요.
- 자동 정기 수집은 아직 활성화하지 않았습니다. 데이터 갱신은 Actions에서 수동 실행합니다.

## 개발 및 검증

Node.js 22.13.0 이상을 사용합니다.

```bash
npm ci
npm run build:pages
npm run test:pages
npx tsc --noEmit --incremental false
```

배포 디렉터리는 `dist-pages/`입니다. GitHub Pages 프로젝트 경로 `/realestatedash/`를 사용합니다.
API 인증키는 빌드·프런트엔드에 전달하지 않습니다. Naver 지도 Client ID는 별도 공개 변수이며 새 웹 서비스 출처 등록이 필요합니다.
기존 서버 구현의 회귀 검사는 `npm test`입니다. [기존 D1 적재 안내](docs/trade-ingestion.md)는 레거시 서버용이며 현재 Pages 운영에는 사용하지 않습니다.

## 출처와 주의

국토교통부 실거래 신고 자료는 취소·정정될 수 있습니다. 화면 가격은 억원, 전용면적은 ㎡ 기준입니다. 수집 범위·시각을 확인하고 원문 및 현장 정보를 함께 확인하세요.
GitHub Pages 용량·트래픽·상업적 사용 정책을 준수해야 하며, 광고/사업화 전 호스팅 적합성을 재검토하세요.
