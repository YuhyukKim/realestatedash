# 서울 아파트 실거래가 배치표

서울 아파트 매매 실거래 신고가를 가격대별로 자동 분류하고, 자치구와
전용면적과 건축연식 조건으로 비교한 뒤 Excel 파일로 내려받는 웹 대시보드입니다.

## 주요 기능

- 10개 가격 구간 자동 분류
- 서울 전체 및 25개 자치구 토글
- 6개 전용면적 구간 토글
- 계약연도 기준 건축연식 구간 토글
- 단지별 1·3·5·10년 및 전체기간 매매·전세 실거래가 차트
- 전용면적별 최근 매매·전세·월세 실거래 상세 패널
- 동·아파트명 검색
- 요약 지표와 거래 상세 표시
- 현재 필터 결과를 `.xlsx` 파일로 다운로드
- 모바일·태블릿 반응형 레이아웃

## 데이터 연결

공공데이터포털의 `국토교통부_아파트 매매 실거래가 자료`와
`국토교통부_아파트 전월세 실거래가 자료` API를 사용합니다.
`MOLIT_API_KEY`가 설정되면 실제 신고 자료를 조회하고, 설정되지 않은
환경에서는 UI 확인용 예시 데이터를 표시합니다.

```bash
cp .env.example .env.local
```

`.env.local`에 공공데이터포털 일반 인증키를 입력합니다.

```env
MOLIT_API_KEY=your_data_go_kr_service_key
```

## 로컬 실행

Node.js `22.13.0` 이상이 필요합니다.

```bash
npm install
npm run dev
```

배포용 빌드는 다음 명령으로 검증합니다.

```bash
npm run build
```

## 데이터 출처

국토교통부 실거래가 공개 자료는 신고 취소·정정에 따라 변경될 수 있습니다.
가격은 억원, 전용면적은 제곱미터(㎡) 단위로 표시합니다.
