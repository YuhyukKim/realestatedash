# 내집어디 탐색·비교 개선

참고 화면: https://www.findapt.co.kr/matrix_pc.php (2026-09-12 확인)

파인드아파트의 조건 검색 → 후보 선택 → 상세 확인 흐름을 참고했다. 코드, 브랜드, 이미지, 거래 데이터는 복제하지 않았다.

## 적용
- 기존 내집어디 정체성과 서울 단지 마스터 유지. 가격 구간별 결과 묶음은 재도입하지 않음.
- 1280px 이상에서는 결과 목록과 상세 패널을 함께 표시. 작은 화면은 기존 전체 화면/모달 방식.
- 상세에서 실거래 차트·목록을 먼저 표시하고 지도·교통·학교 바로가기 제공.
- 목록/비교표 전환, 조건 칩 개별 해제, 모바일 필터 접기.
- 관심 단지: 로그인 없이 이 브라우저의 localStorage에 최대 200개 ID만 저장. 다른 기기 동기화 없음. 저장 불가 시 안내.
- 비교 후보: 최대 3개, 검색 조건 변경 시 유지, 이번 방문 동안만 보존. 현재 선택월/면적에 맞춰 원본 저장 자료에서 비교. 계약일·거래 면적을 함께 표시.
- 미확인 자료는 0원으로 표시하지 않음. 직선거리와 추정 통근 정보의 의미 유지.

## 이번 변경에 포함하지 않은 것
- 수도권 범위 확대, 경로 API 기반 실제 통근 시간, 타 사이트 가격 복제
- 전체 실거래 이력 신규 수집, 계정·로그인, 서버 저장·기기 간 동기화
- 네이버 API 신규 등록 및 인증 설정
